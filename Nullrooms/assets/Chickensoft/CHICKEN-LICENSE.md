# Chickensoft Chicken attribution

The source chicken model is **Chickensoft Chicken** by hardboileduser.

- Model source: https://opengameart.org/content/chickensoft-chicken
- Downloaded asset: `chickensoft_mascot.glb`
- Model license: CC-BY 4.0
- Animation license: CC0 1.0
- Original project: https://github.com/chickensoft-games/chickensoft
- Animation contributor: Thibaud Goiffon

The game keeps the GLB as the authored reference asset. The runtime path tracer
uses a compact low-poly procedural rendition so the easter egg can be rendered
through the existing packed object buffer without adding a second mesh runtime.
